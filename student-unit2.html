Key vocabulary
FunctionA named, reusable block of code that does one specific thing.
ParameterAn input a function needs to do its job. Passed in when calling the function.
Return valueThe output a function gives back when it finishes running.
ModularizationBreaking a large program into smaller, named functions to make it easier to read and test.
REPLRead-Eval-Print Loop. The interactive Python prompt in Mu Editor where you can test code instantly.
L298NA motor driver chip that lets a microcontroller control the speed and direction of DC motors.
PWMPulse Width Modulation. A way of controlling average power to a motor by rapidly switching it on and off.
Design reportA structured document or slides explaining the current state of your project: what problem you're solving, what your solution does now, and what evidence you have.
